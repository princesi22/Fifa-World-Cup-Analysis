⚽ FIFA World Cup Analytics Dashboard (1930–2014)

📌 Project Overview

This project is an interactive FIFA World Cup analytics dashboard that provides a historical, performance-driven view of World Cup tournaments from 1930 to 2014.
The dashboard transforms raw football data into clear, visual insights covering champions, host nations, finals, semi-finals, and qualification trends.

It is designed to demonstrate data visualization, storytelling, and analytical thinking using real-world sports data.



🎯 Objective

The goal of this project is to:
	•	Analyze World Cup performance trends across countries
	•	Identify top-performing teams over decades
	•	Visualize host countries and winning patterns
	•	Present insights in a recruiter-friendly, executive-level dashboard



📊 Key Insights & Visuals

🏆 Countries That Won the World Cup
	•	Brazil leads with 5 titles
	•	Italy and Germany follow as consistent top performers
	•	Clear comparison of total championships by country

🥇 Teams by Finals & Semi-Final Appearances
	•	Highlights consistency vs. peak performance
	•	Brazil, Germany, and Italy dominate finals and semi-finals
	•	Shows long-term dominance rather than one-time success

🌍 Countries That Hosted the World Cup
	•	Identifies nations that hosted multiple tournaments
	•	Includes hosting years for historical context
	•	Useful for understanding geographical distribution

📅 World Cup Results (1930–2014)
	•	Timeline representation of World Cup history
	•	Central visual focus on the World Cup trophy
	•	Adds storytelling and visual engagement

🏟️ Finals: Year, Winner & Stadium
	•	Detailed table with:
	•	Winner
	•	Runner-up
	•	Host country
	•	Final stadium
	•	Enables tournament-level deep dives

🌐 Countries Qualified for the World Cup
	•	Brazil leads with 20 qualifications
	•	Shows qualification consistency across nations
	•	Reflects football infrastructure strength
